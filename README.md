# Twine Storyline：游戏叙事第三讲演示故事

《游戏叙事》第三讲“把一个选择做成可以玩的东西”课上用到的 Twine 故事，共 12 个。故事格式为 Harlowe 3（用 3.3.8 写成，网页版 Twine 打开时会自动升到 3.3.9，写法不变）。

> 这些 `.html` 是 **Twine 的故事库文件**（只存故事数据），不是可以直接双击玩的游戏。要先导入 Twine，才能编辑、测试，或导出成可玩的文件。

## 在本地使用（Twine 桌面版）

### 1. 安装

到 [twinery.org](https://twinery.org) 下载 Twine 2 桌面版（macOS / Windows / Linux），安装后打开。界面默认跟随系统语言；要改成中文，点顶部 **Twine → 偏好 → 语言**，选“中文(简体)”。英文界面的路径是 Twine → Preferences → Language。

### 2. 导入故事

1. 下载本仓库：页面右上角 **Code → Download ZIP**，解压。
2. 在 Twine 故事库里点顶部 **库 → 导入**，英文界面是 Library → Import。
3. 选择 `一次导入_全部12个故事.html`，12 个故事会一起出现在故事库里。只要其中一个，就选 `stories/` 里对应的单个文件。

导入以后，桌面版会把每个故事各存成一个文件，放在“文稿／Documents”下的 `Twine/Stories` 文件夹。这里的文件是 Twine 自己维护的，不用手动改。

### 3. 试玩与查看记录

打开一个故事，点顶部 **构建 → 测试**。测试页面右下角有调试栏，Name 列是记录名（如 `$power`），Value 列是当前记下的内容。用作品结尾的“重新开始”换另一条路，浏览器刷新不算重新开始。

### 4. 给别人一个能直接玩的文件

打开故事，点 **构建 → 发布到文件**，英文界面是 Build → Publish to File。得到的 `.html` 双击就能在任何浏览器里玩，不需要安装 Twine。

### 5. 重新导入前

如果故事库里已经有同名故事，导入时 Twine 会询问是否替换。上课前想恢复成原始版本，就替换。

## 用网页版也可以

不想安装的话，用浏览器打开 [twinery.org/2](https://twinery.org/2)，操作和上面一样。网页版的故事存在浏览器里，清缓存或换浏览器就没了，用完记得“发布到文件”或“库 → 档案”备份。

## 用 AI 智能体改故事（ai-agent-demo）

Twine 的故事可以导出成 Twee：一种纯文本格式，每个片段以 `:: 片段名` 开头，下面是正文。Claude Code、WorkBuddy、DeepSeek Harness 这类命令行或桌面智能体能直接读写本地文本文件，所以流程是：

1. Twine 里打开故事，**构建 → 导出为 Twee**，存进 `ai-agent-demo/` 这样的文件夹；本仓库 `twee/` 里已经有现成的。
2. 在这个文件夹里启动智能体（如 `claude`）。它会先读 `CLAUDE.md`：哪些可以改、哪些不能改、改完必须做什么。
3. 用 `课上指令.md` 里的指令让它加属性表、道具清单、事件记录。
4. 它改完会运行 `python3 tools/check_twee.py <文件>`：查断链、死路、走不到的片段、宏里的全角标点、只设不读的变量。
5. 回 Twine：**库 → 导入**，先点故事名把它选中，再点“导入选中文件”。然后 **构建 → 测试**，两条路各走一遍。

规则只有一句：**可以改结构，但必须验收。** 检查脚本只查结构，台词对不对、选择有没有意思，仍然要人自己玩一遍。

`ai-agent-demo/起点/` 是改之前的版本，`结果/` 是课上演示改好的版本，都已在 Twine 里测试过。

## 重新生成

改了 `tools/build_demo.py` 里的故事正文以后，在 `tools/` 文件夹里运行：

```
python3 build_demo.py
```

新文件会生成在 `tools/` 文件夹里，再按需要替换上面的文件。
