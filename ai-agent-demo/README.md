# AI 智能体 × Twine 演示（第三讲 P35—P36C）

让 Claude Code 这类 AI 智能体直接读写 Twine 故事文件，帮忙写叙事、加角色属性、道具清单和事件记录，并自动检查。

## 文件
| 文件 | 用途 |
|---|---|
| `起点/交接还是救人_起点.twee` | 演示 06 的 Twee 版，交给 Claude Code 改之前的样子 |
| `结果/交接还是救人_属性版.twee` | 改完应得到的样子（课前做好、已在网页版 Twine 实测两条路） |
| `CLAUDE.md` | 给 AI 智能体看的规则：能改什么、不能改什么、改完必须检查 |
| `课上指令.md` | 课上依次输入的三条指令 |
| `tools/check_twee.py` | 自动检查：断链、死路、走不到的片段、全角符号、闲置记录 |
| `tools/html2twee.py` | 把 Twine 故事库 HTML 转成 Twee |

## 流程
1. Twine 里：构建 → 导出为 Twee，存进本文件夹（或直接用 `起点/` 里的文件）。
2. 在本文件夹打开 Claude Code，输入 `课上指令.md` 里的指令。
3. Claude Code 改完、跑过检查后，回 Twine：库 → 导入（选好文件后，先点故事名选中，再点“导入选中文件”），选新生成的 `.twee`。
4. 构建 → 测试，两条路各走一遍，看右下角调试栏里属性和记录的变化。

## 实测记录（2026-10-21，网页版 Twine，Harlowe 3.3.9）
- `.twee` 文件可直接通过“库 → 导入”导入。
- 属性版：救人 → 信任 0、心情“失望”、道具“箱子 + 店主的名片”，结尾回顾两件事；赶路 → 信任 3、心情“满意”、箱子已交出。
- 课前试跑（2026-10-21）：让一个全新的 Claude Code 会话只读 CLAUDE.md，照“课上指令”一、二从起点版做起，两次检查都通过；生成结果与 `结果/` 版思路一致，措辞不同。
- 检查脚本：对 12 个演示故事，能报出 02 的死路、备用 11 的断链；“看不懂”“对不上”“经历被清空”这类语义问题查不出，仍要请人来玩。它也只查整个记录有没有被读，查不到属性表里的单项属性。
