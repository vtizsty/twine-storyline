# 课上给 Claude Code 的指令（老师演示用）

在本文件夹打开 Claude Code（终端里 `cd` 到这里再运行 `claude`，或在 Claude 桌面版的 Code 里选这个文件夹），按顺序输入。每条指令执行完，到 Twine 里“库 → 导入（选好文件后，先点故事名选中，再点“导入选中文件”）”新文件，两条路各走一遍。

## 指令一：角色属性表 + 事件记录（P36A）

```
读 起点/交接还是救人_起点.twee。
1. 给阿青建一张属性表：信任（初始 2）、心情（初始“平静”），放在新建的“初始化”片段里，加 startup 标签。
2. 码头：救人迟到，信任 -2、心情“失望”；准时，信任 +1、心情“满意”。
3. 用 $log 记下玩家做过的事（救人或赶路、迟到或准时）。
4. 结束：按信任决定阿青第二天还找不找你；最后列出“这一夜你做过的事”。
另存为 我的版本/交接还是救人_属性版.twee，然后跑检查。
```

## 指令二：道具清单（P36B）

```
在 我的版本/交接还是救人_属性版.twee 里加一个道具清单 $items：
开始时有“箱子”；救人时店主给你一张“店主的名片”；准时交接后箱子交给阿青。
结束时：箱子还在，就写一句；有名片，就写名片背面的一句话。跑检查。
```

## 指令三：只检查不改（P36B 结尾，可选）

```
对 ../演示文件_Twine维修站_2026-10-17 里的错误版故事跑检查（先用 tools/html2twee.py 转成 twee）。
说明每个问题属于“跑不通、看不懂、对不上、经历被清空”中的哪一类，给出修法，但先不要改文件。
```

## 现场出问题时
- Claude Code 写出来的和预期不一样：直接打开 `结果/交接还是救人_属性版.twee`，这是课前做好、实测过的版本。
- 导入 Twine 后出现紫红色报错条：多半是代码里混进了全角符号，让 Claude Code 跑一次检查并修正。
